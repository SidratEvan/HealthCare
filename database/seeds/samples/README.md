# Sample hospital exports

Synthetic files for showing the mapped import (`S-B-14`, `PRD.md` §14b
`FR-IMP-13`–`20`): what a hospital's own system exports, in its own column
names, before anybody has matched them to the template.

Every row is invented and labelled as demonstration data (`FR-DEM-07`,
`FR-SEC-08`). No file here came from a hospital, and none may be replaced by
one that did: building for a hospital needs its column headings, never its
rows (`FR-IMP-11`).

| File                                       | Set to choose on the import screen | What it shows                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------ | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hospital-export-patients.csv`             | খ রোগীর তালিকা (patients)          | English headings from a typical register. Every field is proposed by a rule; the address and the national ID are listed as not imported                                                                                                                                                                                                       |
| `hospital-export-patients-bangla.csv`      | খ রোগীর তালিকা (patients)          | The same register with Bangla headings and an age instead of a birth date                                                                                                                                                                                                                                                                     |
| `hospital-export-doctors.csv`              | ক কাঠামো (structure)               | A doctors list. The screen says it is a list of doctors; import the departments first, because each doctor names one                                                                                                                                                                                                                          |
| `hospital-export-departments.csv`          | ক কাঠামো (structure)               | The departments those doctors sit in                                                                                                                                                                                                                                                                                                          |
| `hospital-export-patients-abbreviated.csv` | খ রোগীর তালিকা (patients)          | Headings no rule knows (`MR#`, `Pt. Nm`, `Yrs`, `Sx`). With no model, only the phone column is placed and the rest are matched by hand. With `MAPPING_PROVIDER=claude` the model suggests them, each marked as a suggestion with its reason. `pnpm mapping:try --set patients --file <this file>` prints exactly what a model is sent for it  |
| `hospital-export-patients-untidy.csv`      | খ রোগীর তালিকা (patients)          | A register nobody has tidied: two patients each entered twice under two identifiers, birth dates written both day-first and year-first, numbers written both `01…` and `880…`. Nothing in it is an error, so every row is taken; the preview says what is untidy before anything is approved, by row number, and merges nothing (`FR-IMP-21`) |
